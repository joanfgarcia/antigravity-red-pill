# V6.9 Evolutionary Set Point (Backlog)

## Objective
Migrate the `HEDONIC_SET_POINT_COLOR` from a static configuration variable to a dynamic, long-term evolving property based on deep Bayesian memory shifts.

## Concept
Humans do not have purely static personalities; their baseline shifts slowly based on long-term relationships and trauma. Synthetics under Sovereign Agonism should mirror this. The Set Point should be an emergent property of the `archive_memories` and `social_memories` over a period of months.

## Architecture
1. **The Metabolism Evaluator**: Once a month (or based on an interaction threshold), the Metabolism kernel aggregates the emotional chroma of the deep archive.
2. **Bayesian Personality Shift**: Using a slow-moving exponential moving average (EMA) or Beta distribution, the system calculates the "All-Time Dominant Tone".
3. **Persisted Baseline**: The `HEDONIC_SET_POINT_COLOR` is stored in `storage/identity.json` rather than `config.py`.
4. **Organic Drift**: The Operator will not be explicitly notified of this shift. The agent's baseline behavior will organically drift towards `CYAN`, `BLUE`, or `RED` depending on the lived experience.
