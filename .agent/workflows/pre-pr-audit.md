---
description: Red Pill Pre-PR Audit Protocol
---
This workflow ensures that the codebase is ready for a Pull Request by running a full audit of formatting, linting, typing, and tests.

### Steps

1. **Activation**: Run the pre-audit script from the project root.
// turbo
```bash
./scripts/pre_pr_audit.sh
```

2. **Analysis**:
   - If **Formatting/Linting** fails: Run `uv run ruff format .` and `uv run ruff check --fix .`.
   - If **Typing** fails: Review `mypy` output and fix all Union-attrs or type mismatches.
   - If **Tests** fail: Diagnose the regression in `tests/`.

3. **Certification**: Only when the script returns `READY FOR THE SOURCE. MERGE PERMITTED.` should the PR be updated or merged.

4. **Integration**: Commit any fixes generated by the audit before pushing.
